# Teen Tech Technology — Smooth Website Demo

A lightweight one-page demo of the "smooth website" style by **Teen Tech Technology** (Lusaka, Zambia).

**Live:** https://teentech-technology.github.io/teentech-demo/

## Stack
- Plain HTML, CSS and JavaScript (no build step)
- [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- [Lenis](https://github.com/darkroomengineering/lenis) smooth scroll (CDN)
- [GSAP](https://gsap.com/) + ScrollTrigger for subtle reveal animations (CDN)
- Inline SVG icons, no images — fast on mobile data

## Features
- Dark UI, accent `#156CF1`, sticky blurred glass navbar, animated hero glow
- Mobile-first responsive layout
- Respects `prefers-reduced-motion` (disables smooth scroll and animations)
- Content stays visible if the CDN scripts fail to load

## Run locally
Open `index.html` in a browser, or `python3 -m http.server`.
